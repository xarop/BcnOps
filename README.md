# BcnOps

Repositori de suport operatiu per a l'administració i gestió de proves i convocatòries educatives de Barcelona (Àmbit Metropolità Públic).

## Contingut del repositori

- `index.html` — Plantilla principal d'actuació quotidiana per a l'equip d'operacions.
- `2026_31_Ampliacio_borses_2026_Anunci_convocatoria_24_octubre.pdf` — Convocatòria d'ampliació de borses (24 octubre 2026).
- `Instruccions_generals_ASPIRANTS_Borses_2026_per_publicar.pdf` — Instruccions generals per als aspirants a borses 2026.
- `TOTS_els_mapes_ubicacio_proves_24_octubre_2026.pdf` — Mapes d'ubicació de proves per a l'14 octubre 2026.
- `styles.css` — Estils compartits per a la plantilla HTML.
- `questions.json`, `questions_test.json`, `questions_probed.json` — Qüestions i superfície de proves per a proves diagnòstiques i finals.

## Ús

Aquest repositori és de caràcter operatiu intern. Les dades sensibles (noms d'aspirants, identificadors personals) no s'han d'incloure; només es publiquen documents oficials de convocatòria i suports de prova.

## Estructura de convocatòries

| Fitxer | Contingut |
|--------|-----------|
| `2026_31_Ampliacio_borses_*` | Ampliació de borses – convocatòria i anuncis |
| `Instruccions_generals_ASPIRANTS_Borses_2026_*` | Instruccions generals per a aspirants |
| `TOTS_els_mapes_ubicacio_proves_24_octubre_2026.pdf` | Mapes de ubicació de proves (14 octubre 2026) |

## Instruccions finals

1. Revisa els mapes de ubicació abans de cada sessió de proves.
2. Obté la còpia de les instruccions generals dels aspirants a la carpeta corresponent.
3. Mantingui l'actualització del README amb els canvis operatius de cada convocatòria.
4. Contacta amb l'equip BcnOps si necessites afegir documents nous.

## Llicència

Dades obertes per a ús intern; consulta el document oficial per a la distribució exterior.
